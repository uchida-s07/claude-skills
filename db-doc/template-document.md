## 2. データモデル関連図

RDBのリレーションではなく、**ドキュメントの入れ子（サブコレクション・埋め込み）**を示す。
`||--o{` は「配下にサブコレクションを持つ」または「配列で埋め込む」の意味で使う。

```mermaid
erDiagram
    ROOT_A ||--o{ SUB_B : "サブコレクション"
    ROOT_A ||--|| EMBEDDED_C : "埋め込み(Map)"

    ROOT_A {
        string id "ドキュメントID"
        string name
        timestamp created_at
    }

    SUB_B {
        string id "ドキュメントID"
        string status
        timestamp created_at
    }

    EMBEDDED_C {
        string field "親ドキュメント内のMapフィールド"
    }
```
